程序与 Qwen 都在生成菜单时排除两类可直接判错的候选。新增反向边会形成二元环；删掉必有正效应的干预源的最后一条出边会丢失必要路径。这两类检查只读边列表，另外记录筛除数，未计入完整图探查。

程序、Qwen 分支累计筛除数分别为 107、85。

同一搜索状态下，Qwen 选对 132/133，程序首选正确 133/133。Qwen 救回 0 槽，选错 1 个程序本可通过的槽。整题合法图数胜／平／负为 0 / 23 / 1。

既有程序避险沿用原来的排序，作为更强的参考基线。本测试限制每槽一次探查。正式流程可使用更宽预算或直接构造。
