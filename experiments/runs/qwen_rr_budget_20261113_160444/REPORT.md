# Qwen3 8B 的 128 槽对照

六道六节点题按干预数 1–6 各固定抽取一道，每题一个采样种子。每槽向本机 Qwen3 8B 请求一张图，共 768 次调用。沿用观测与重复反馈、路径与环路诊断，前七答均无合法图时在第八槽启用思考。第九槽起继续普通生成，提示只保留最近八条历史，评分在全轮去重。所有候选图都来自模型答复。
