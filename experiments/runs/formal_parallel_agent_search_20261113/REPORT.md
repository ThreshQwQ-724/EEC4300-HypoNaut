# HypoSpace 正式对照 · 双 Agent 独立探索

原正式 24 道六节点题，每题 8 槽。两个探索组与程序对照共享程序首图，首图占第一槽。探索组先独立生成两个候选，用不同种子，第二个候选看不到第一个。Ollama 串行执行请求。有新合法图则提交一张，剩余候选缓存。两次提案均无新合法图时，第三次调用使用程序诊断修复。合法性及去重以验证器为准；空槽计入 VR 和 NR。

双 Agent 组增加角色提示，A 从最新合法图做单边编辑，B 从边集距离最远的已提交图出发。上一槽未找到图且存在未检查的联合编辑时，B 优先尝试 Shift。操作类型由提示引导，实际验收只检查合法性与去重。单 Qwen 两次使用相同的通用提示。程序组共用首图，沿用单边避险，每槽最多探查三个候选。既有 Debate 未使用程序首图，调用预算也不同，作为历史参照。
