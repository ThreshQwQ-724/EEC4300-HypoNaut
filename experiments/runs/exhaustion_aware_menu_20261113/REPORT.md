# 候选搜索停机验证

完整观测从可达关系构造传递约简。约简中的边必须存在，其余已知可达边均为可选边。在边数限制内计数组合，找到同样数量的互异合法图即可确认全局找齐。答案数只用于回放评分。

部分观测缓存经精确单边预判排除的候选。若已提交图的增删邻居都已排除，只证明当前单边连通分量搜尽。剩余未验证候选或提交预算用尽时保留 unproven。当增边候选均被排除时，可在同一预判上限内切到删边候选。

每槽最多预判 32 个候选，最多执行一次完整验证。前后对照复用上次同一批 60 题。
