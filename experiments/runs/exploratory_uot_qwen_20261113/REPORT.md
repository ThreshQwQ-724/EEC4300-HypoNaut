# HypoSpace Exploratory UoT 对照

方法来源 [https://arxiv.org/html/2511.20471v3](https://arxiv.org/html/2511.20471v3)。

24 道六节点题，每题 8 个提交槽，各策略共享观测、首图和验证器。每槽至多检查指定数量的未验证候选，找到第一个新合法图即提交。每个候选算一次探查；单边沿用程序避险，联合改动直接验证，因此同时列出完整验证、删边遍历与耗时。首图校验与最后独立复核不计入搜索成本。答案数只用于抽样、评分与结果审计。

Deepen 为单边增删，Shift 为直接边与两跳路径的双向替换。两种混合策略共享邻域和程序顺序。程序在第 4、7 槽优先尝试 Shift，其余槽优先 Deepen。两类操作从所有已提交图扩展。Qwen3:8B 通过结构化 JSON 选择最多 8 个父图/操作家族的代表候选，关闭思考。无效编号使用程序首选，剩余检查沿用程序顺序。

RR 按题宏平均。各组只提交已验证且不同的图，因而 VR 与 NR 相同。运行秒数为本次执行时间，模型请求秒数来自原始请求记录，重跑使用缓存时两列口径不同。逐题检查、候选菜单与模型请求见同目录 JSON。

Qwen 样本按 2–5 次干预分层随机抽取，每题至少有 8 个合法解，并排除既有运行配置中的题号。1 次与 6 次干预层满足条件的题号都已出现在既有配置中，故本次 Qwen 对照未纳入这两层。
