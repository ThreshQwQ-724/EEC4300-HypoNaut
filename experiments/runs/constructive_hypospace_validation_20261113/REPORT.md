# HypoSpace 构造式搜索原始数据复核

每题固定 8 个提交槽。六节点组流式读取原始 HypoSpace 文件，直接从文件中的观测求解，再逐项扫描所有标准答案，用边集核对每张输出的图。四节点组使用工作区已有的 HypoSpace 生成器完全观测数据，直接传完整答案集给官方评分器。

两个题集均复用原始评分器的单题评测入口。六节点组仅把原始答案中匹配到的图传给评分器，其余答案在流式扫描中用边集去重后计数。RR 用官方评测返回的命中数除以这个完整的去重计数。原始答案不进入求解过程。

时间仅含本轮求解，不含扫描原始数据和事后评分。完整检查含首图和回退检查。四节点组每题都是完全观测，只用于检验尺寸迁移。两种方法均无模型调用。
