# HypoSpace 候选编号对照

16 道六节点题，每题 8 槽，每个后续槽最多探查 1 个未验证候选。三组共享程序首图、剪枝、单边邻域与验收规则。一次探查包含风险判断，通过后做完整验证。编号菜单仅用静态观测剪枝，未预先逐图验证。候选菜单会随各组历史变化。

单 Qwen 从两张不重叠的菜单并集选编号，双 Qwen 的 A 优先看增边，B 优先看删边和其他父图。A 的候选未通过且预算允许时才调用 B，剩余预算由程序排序补位。单探查时双 Qwen 只调用 A。无效编号交给程序处理。各组找到新合法图后立即提交，每槽最多提交一图。
