# Agent B 补位对照

每题 8 槽，共享程序首图。每个后续槽至多两次探查。两组的 A 沿用编号版的增边优先菜单。A 的图被拒绝后，两组从同一规则生成最多 8 张未验证候选，可跨增边、删边及父图。备选排序优先保留可用两跳替代路径解释的改动，其次避免与失败边共享端点。程序组取首项；Agent B 组收到具体失败类型，选择编号。无效编号回到程序首项。

排序使用父图的局部边信息。每次实际探查才做风险判断和必要的完整验证。旧编号版结果来自同题历史记录。24 道正式题的旧编号版使用三查预算，因此表中仅列同为两查的新组。

逐题胜／平／负按合法图数计算。
- 独立 16 题，Agent B 对程序补位为 0 / 16 / 0。
- 正式 24 题，Agent B 对程序补位为 0 / 22 / 2。

两个题集已经用于先前编号实验，属于同题策略复测。补位后生成历史可能分叉。

## 同一槽位的备选诊断

旧版在 16 题中调用 B 四次，三次菜单里有合法图，实际选中一次。其中一次四个候选均无效，另两次菜单中存在合法图但模型选错。

在新版 B 实际收到的 15 个菜单上，逐一用同一验证器回放程序首选。程序首选 15 次均合法，B 选中 11 次。正式题上的四次差异均为程序首选合法而 B 选错。该诊断使用相同搜索状态，避免后续提交历史分叉影响比较。

在两种选择均合法且存在未观测节点的 11 个槽位上，比较候选对这些节点预测的可达性是否给出了历史中未出现的模式。B 的选择在两个槽位新增一种模式而程序首选没有，其余九个槽位相同。样本来自两组同题复测，适合据此设计多样性对照。
