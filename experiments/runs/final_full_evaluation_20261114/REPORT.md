# HypoSpace 三题型全量复测

使用同题同种子、8 个提交槽，沿用 Qwen3:8B 非思考模式。覆盖本地全部 674 道题。Boolean 的原策略沿用冻结的 80 题结果，短菜单重新推理。3D 两种 Qwen 策略和因果图两种 Qwen 策略重新推理。

Boolean 在当前剩余菜单上按候选输出的多数一致性排序，并用分割均衡度打破平局。程序取首项，Qwen 在同一规则的前八项中选编号。随后沿用全部反例剪枝。排序读取公式在观测输入上的输出，不使用观测标签，每题预先计算 65×观测数 个公式输出，剪枝与验收再读取标签。

3D 的方法共享八套方案。以正交相邻柱的有向高度差向量种类作为额外指标。新提示直接提供每套方案的模式数。程序对照取最大值。

因果组从同一合法首图出发，排序一次最多给出四个不同候选。在后续槽依次消耗排序，每槽最多验证两个候选；本槽队列用完时下一槽再补充。程序按同一菜单的既有顺序取前四项。最终沿用同池预测多样性补位。

## 结果解读

- Boolean 的短菜单比旧 Qwen 策略提高 1.42 个百分点的修正版 RR，输入 token 从 257,798 降到 111,697。原版 RR 从 38.19% 降到 37.65%。同排序程序对照的修正版 RR 为 66.01%。
- 3D 两种 Qwen 方案和程序对照均达到每题 8 个合法解。相邻高度差模式为额外指标，程序直接取最大值与新 Qwen 提示同分。
- 因果图的路径反馈重选在补位前多找到 61 图，RR 高 0.64 个百分点。补位后三组均达到 8 槽预算下的逐题上限。批量 Qwen 的调用较逐槽 Qwen 减少 74.2%，部分观测题的预测模式数从 6.13 增至 7.05，同菜单程序批量为 7.02。
- 从因果图原始 Ollama 响应汇总，路径反馈重选的 3,623 次调用用了 1,348,029 个输入 token 和 25,331 个输出 token，批量排序的 934 次调用用了 244,278 个输入 token 和 26,440 个输出 token。逐槽重选的输入 token 未传入汇总脚本，summary.json 中该项的 0 是缺失值。

## 评分复核

逐题重放共 4,204 个评分结果，全部匹配。Boolean 和 3D 同时复核原版和修正版。因果图逐题扫描原始答案，核验三种策略补位前后的图、提交位置和指标。每种题型的 audit.json 保存逐题结果文件的摘要。
