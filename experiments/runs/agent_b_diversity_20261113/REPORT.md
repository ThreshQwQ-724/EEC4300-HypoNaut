# Agent B 合法候选多样性对照

每题先以程序构造首图，再用共享单边搜索预先收集至多 32 张合法图。三组用同一首图和同一候选池，各选至多 8 张不同合法图。程序边集距离组按边差异排序，程序预测组优先选新预测模式，再最大化与已提交图的最小可达性差异。B 从程序预测排序前 8 个不同模式的代表图中选编号，每槽至多调用一次。各组的已提交历史可随选择变化，候选池固定。

预测模式是每个未观测干预节点的全部可达目标的组合。平均两图差异按未观测干预的可达性位计算，再按题平均。完全观测题没有未观测干预，单独计入正式 RR、VR、NR，不进入多样性均值。

正式 24 题，B 相对程序预测排序的逐题模式数胜／平／负为 0 / 18 / 2。固定在 B 当时的选择状态，B 有 4 次选到旧模式而程序首选是新模式。共享建池执行 2629 次探查（首图另计）。

独立 16 题，B 相对程序预测排序的逐题模式数胜／平／负为 0 / 15 / 1。固定在 B 当时的选择状态，B 有 3 次选到旧模式而程序首选是新模式。共享建池执行 1776 次探查（首图另计）。

独立样本排除了已有实验配置中的题号，程序全量诊断此前覆盖过这批题。模式上限只针对固定候选池。各组均只提交经验证且不同的图，因此 VR 和 NR 相同。
