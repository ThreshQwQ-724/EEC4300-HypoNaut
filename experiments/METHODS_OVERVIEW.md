# HypoSpace Final Project 实验总览

核心问题是，在固定提交槽位与验证预算下，如何找到更多不同合法机制。对照须共用题目、种子和评分口径。下列开发实验用不同题集，分别回答各自的实验问题。正式分数以同题配对报告为准。

| 阶段 | 方法 | 观察到的结果 |
|---|---|---|
| 采样参数 | 固定温度、动态温度、逐槽换种子 | 温度和种子调整未在新题上提高覆盖率。普通模式保留 Qwen3 8B、温度 0.60。 |
| 反馈 | 重复提示、观测一致性、路径与环路诊断、累计约束 | 路径与环路反馈在一批新题上改善了 RR。累计约束在不同题上的表现不一致。 |
| 推理预算 | 第 5 或第 8 槽按失败触发思考 | 六题的两种触发时机都达到 29.17% RR，第 8 槽方案用较少 token。另 18 题上，诊断加末次思考为 34.16% RR，B 基线为 13.89%。 |
| 找到首图后搜索 | 对合法图增删一条边、按观测验证和去重 | 原 18 题 RR 从 34.16% 到 58.47%。部分观测四节点题从 6.94% 到 13.89%。 |
| 提前单边修复 | 前四槽无解时，第五槽尝试修复已生成图 | 独立八题验证中，仅搜索为 38.70% RR，修复加搜索为 52.77%。 |
| 程序首图 | 从正可达关系构造 DAG，再做传递约简和观测验证 | 六道部分观测六节点题的程序首图组达到 8 槽覆盖上限。Qwen 从已验证候选中选图没有增加合法图数。 |
| 观测剪枝 | 由已知正负可达关系排除不可能的边 | 全部 510 道六节点题上，固定每槽最多 8 查的剪枝组达到覆盖上限。 |
| 按需检查 | 优先使用已验证候选，池空时每批增加检查 | 510 题保留 27.49% RR，每题平均检查从 42.58 降至 9.95。默认 12 次上限来自这批题。 |
| 扩展提交预算 | 共享搜索队列，比较 8、16、32、64、128 槽 | 510 题在 128 槽达到 49.36% RR，预算上限 49.39%。六道 Qwen 对照题在第 8 槽后未新增合法图。 |
| 紧预算选边 | 程序排序、增边优先、Qwen 从未验证菜单选边 | 每槽只查一次时，Qwen 曾超过普通程序排序。独立 12 题上加增边规则后，Qwen 找到 91 图，程序 89 图。每槽两查时持平。 |
| 选择性调用 | 上槽失败再询问、基于风险提前询问 | 24 题开发对照中，两种选择性方案均未保住每槽 Qwen 的 RR。 |
| 程序避险 | 用父图缓存可达关系避开可能成环或违反负观测的增边 | 36 道未用于先前模型实验的题上，避险找到 286 图，普通程序 272 图，Qwen 273 图。两道只有 8 个解的题停在 7 图，最后一槽菜单只剩删边。 |
| 布尔跨任务 | 反例反馈、前缀表示、公开文法编号约束 | 结构约束解决了格式和重复。相同约束下反例反馈从 30 增到 31 个合法机制，结果有升有降。原版与修正版必须分开报告。 |
| Agent Debate | 两个 Qwen3:8B 上下文轮流提案与审查，同预算单 Qwen 自审作为对照 | 正式 24 题上，Debate 的 RR 为 0.0040%，单 Qwen 自审为 0.0060%，官方提示为 0.0046%。Debate 提高了相对官方提示的 NR，但降低了 VR。 |
| Debate 校验回退 | 用观测验证草稿与改写，保留会被改坏或被重复图替换的新合法草稿 | 同批正式 24 题重新推理，拦下 16 次无效改写，保留 2 次成功修复。VR 从 7.81% 升到 18.23%，RR 从 0.0040% 升到 0.5305%，NR 从 48.44% 降到 45.83%。不同合法图均为 7 张，RR 的增量主要来自一道只有 8 个合法解的题。 |
| 双 Agent 独立探索 | 共享程序首图，两个 Qwen 上下文分工生成候选，由程序验证和去重 | 同批正式 24 题上，双 Agent 找到 38 张不同合法图，单 Qwen 多次采样找到 28 张，程序单边搜索找到 192 张。双 Agent 对单 Qwen 的逐题胜平负为 3／20／1。 |
| Agent 候选编号 | 从程序生成、尚未验证的单边候选中选择，失败时按预算补位 | 正式 24 题每槽最多三次探查，程序、单 Qwen、双 Qwen 均找到 192 张合法图。独立 16 题每槽最多两查，三组分别找到 128、127、125 张。 |
| Agent B 补位 | A 失败后扩展备选菜单，优先考虑存在两跳替代路径的改动，对比程序首选与 B 选编号 | 两查下，16 题同题复测旧版为 125 张，两种新策略均为 128 张。正式 24 题上程序补位为 192 张，B 补位为 188 张。 |
| Agent B 预测多样性 | 共享预验证候选池，比较边集距离、未观测节点可达性排序和 B 选编号 | 部分观测正式题上平均预测模式数分别为 7.50、7.80、7.65，独立 16 题分别为 6.94、7.38、7.25。程序预测排序达到各题固定候选池的模式数上限。 |
| 约束构造 | 从合法首图沿拓扑顺序添加保留观测可达性的边，数量不足时回退单边搜索 | 正式 24 题均填满 192 槽，完整图检查从 296 降到 24。510 题保持 3,437 张合法图及 27.4881% RR，完整检查从 4,853 降到 628，零模型调用。 |
| 单 Qwen 定向改边 | 根据验证器的错误路径，在原菜单之外组合增删边 | 53 个同题失败状态中，菜单重选、Qwen 改边、程序修复分别找到 11、37、46 张合法图。旧菜单无解的 38 个状态中，Qwen 与程序分别补中 26 和 31 个。 |
| 单 Qwen 正式端到端 | 固定正式 24 题和 8 槽，比较路径反馈重选、程序修复和 Qwen 定向改边 | 三组分别找到 186、186、163 张合法图，RR 为 15.1508%、13.5270%、11.7659%。定向改边有 23 次重复旧菜单或已探查图，34 次尝试共补中 5 张。 |
| 三题型全量评测 | 本地 674 题，统一 8 槽，比较官方提示、任务约束与反馈、程序参照 | 增强版 RR 为 Boolean 16.7026%（修正版）、3D 20.2381%、因果图 26.9474%；相应的官方提示为 0.5172%、3.7478%、6.2276%。 |
